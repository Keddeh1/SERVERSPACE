Dual-network genesis

Child creation provisions a new internal network namespace and downstream bridge. The child also joins its parent’s downstream network. Repeated local ports therefore belong to separate network domains.

State and recovery

When an intermediate anchor disappears, the descendant continues in flywheel. Reanchoring changes the upstream conduit while retaining its downstream network and state epoch. Local tests establish this behaviour on one cloud host; independent WAN failure domains require a separately bound deployment.
