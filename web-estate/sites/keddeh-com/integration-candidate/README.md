## Build and deployment

Static HTML/CSS/JavaScript is directly served without a compilation step. Run `bash .keddeh/launch-family.sh` from this repository to start the pinned owner-family engine and managed frontage process. Family configuration binds the source directory and port; customer data stays in private runtime state outside Git. Download bytes are the distributed runtime wheel.
