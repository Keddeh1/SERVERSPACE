A reproducible severe-noise result

In a new eight-node epidemic SI study with 1,000 seeds per case and 50 rounds, mesh convergence was 100% at 85% dropout; chain convergence was 65.6%. With the same 50-attempt budget, the advantage disappeared in this model. The graph, time horizon and resource budget belong with the result.

This is a new software experiment with retained raw data, not a recovered original trial or physical LIF/RC validation.
