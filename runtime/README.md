# Runtime Package Catalogue

This repository is the home of custom KEDDEH runtime modules and local HTML-based services.

## Included by default

- `runtime/bootstrap.sh` — local custom runtime bootstrap
- `runtime/config/custom-runtime.json` — runtime manifest
- `runtime/dns/resolver.html` — local DNS runtime module
- `sites/keddeh.com/index.html` — website landing page
- `packages/html/keddeh-runtime.html` — example HTML package

All of these files are local and do not require GitHub dependency installation or runtime management.
