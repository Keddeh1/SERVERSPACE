# SECTOR_MATHEMATICAL_LATTICE — EAST +X

Scope: unit-origin four-ray arithmetic, typed zero/reference/results, conjugated operations, relational-field geometry and context-bearing coordinate vectors. [Frame contract](FRAME_CONTRACT.json) specifies the connector envelope and its lineage invariants. It is an explicitly derived adapter schema, not a claim that the identical schema appears verbatim in owner artifacts.

A delta retains the same continuation identity while changing physical carrier. Each event preserves its predecessor, complete context, ray, parameter, exact input and result. The receiving runtime recomputes the operations before admitting the claimed target. Rehashing a false vector cannot make it a valid successor. Directed cross-field admission is required even where scalar values match. KEXE-1 offsets, 64×64 VFS coordinates and arithmetic values retain their separate units.

SHA-256 identifies the admitted event body; canonical JSON remains a real encoding boundary. The implementation reduces repeated transport/validation work through ordered batching; it does not claim all serialization or every external identifier translation vanishes.
